# Customer Interview Meta-Analysis Toolset

This repository provides a reusable, domain-agnostic toolset for conducting
rigorous cross-interview meta-analysis using a quantitative + qualitative
hybrid approach.

It is designed for analyzing customer, founder, operator, or developer
interviews where the goal is to identify:
- The most common problems experienced
- The most desired solutions people want built

The toolset explicitly avoids common failure modes such as:
- Per-interview summaries
- Vague or abstract themes
- Opinion-driven prioritization
- Overgeneralization across participants

Instead, it produces:
- Frequency-ranked problems and solutions
- Concrete, buildable insights
- Explicit attribution to interview sources
- Optional quote-grounded evidence
- A scoring rubric to evaluate analysis quality
